# 📦 Где что лежит — Мобильная система учета и поиска по складу

Современное веб-приложение на **Streamlit** для оперативного поиска ТМЦ, основных средств, пластика для 3D-печати и расходных материалов на складе. Приложение автоматически подключается к Яндекс.Диску по REST API, считывает данные из многостраничного Excel-файла реестра и предоставляет адаптивный интерфейс, оптимизированный для работы как с компьютеров, так и с мобильных устройств.

---

## 🚀 Основной функционал

### 1. 🔍 Поиск по складу
* **Многостраничный поиск:** Быстрое переключение между листами реестра (*Закупки*, *ОС Главная*, *Пластик*).
* **Умный нерегистрозависимый поиск:** Мгновенный фильтр по наименованию, артикулу/коду, куратору или месту хранения.
* **Информативные карточки (`st.expander`):** Отображение статуса, количества/остатка, проекта, ячейки хранения, стоимости и QR-кода.
* **Сводка до поиска:** Статистика по складским позициям на главном экране до ввода запроса.

### 2. 📊 Аналитика и Отчеты
* **3 KPI и 2 графических отчета** индивидуально для каждого листа склада (*Plotly Express*):
  * **Закупки:** Успешность поставок, загрузка ячеек, средняя нагрузка на кураторов МТО, stacked-чарт статусов по сотрудникам и воронка поставок.
  * **ОС Главная:** Коэффициент ввода в эксплуатацию, объем готовых к выдаче ОС, доля неинвентаризированных позиций, размещение по проектам и топ-5 самых затратных отделов МТО.
  * **Пластик:** Суммарный вес филамента в кг, катушки с критическим остатком (< 200г), запасы по типам пластика (PLA, PETG, ABS, TPU) и раскладка по брендам.

### 3. 📷 Сканер QR-кодов
* **Загрузка и камера:** Поддержка загрузки готовых фотографий и снимков напрямую с веб-камеры/камеры телефона.
* **Многоэтапное распознавание (OpenCV):** Предобработка кадра (градации серого, CLAHE, адаптивный порог, Otsu thresholding) для считывания поврежденных и тусклых QR-кодов.
* **Быстрый переход:** Распознавание прямых веб-ссылок с кнопкой мгновенного перехода.

## 🛠️ Стек технологий

* **Python 3.10+**
* **Streamlit** — реактивный веб-интерфейс
* **Pandas** & **python-calamine** — обработка данных и сверхбыстрое чтение Excel
* **OpenCV (`opencv-python-headless`)** & **Pillow** — компьютерное зрение и обработка изображений для QR-сканера
* **Plotly** — интерактивная визуализация данных и аналитика
* **yaDisk** — интеграция с API Яндекс.Диска
* **python-dotenv** — безопасность и управление конфигурацией

## 📂 Структура проекта

Модульная структура обеспечивает чистоту кода и простоту масштабирования:

```text
├── main.py                # Точка входа приложения, настройка страниц и роутинг
├── config.py              # Загрузка переменных окружения и глобальные настройки
├── data_loader.py         # Модуль кешируемой загрузки и обработки Excel с Яндекс.Диска
├── views/                 # Представления (экраны приложения)
│   ├── search_view.py     # Модуль "Поиск по базе"
│   ├── analytics_view.py  # Модуль "Аналитика и Отчеты" (Plotly)
│   └── scanning_view.py   # Модуль "Сканер QR-кодов" (OpenCV)
├── requirements.txt       # Зависимости проекта
├── .env                   # Переменные окружения (секреты, в .gitignore)
├── .env.example           # Шаблон переменных окружения
├── .gitignore             # Исключения для Git
└── README.md              # Документация проекта
```

## ⚡ Инструкция по запуску

### 1. Клонирование репозитория

```bash
git clone https://github.com/BogdanovGleb26/RKKProject.git
cd RKKProject
```

### 2. Создание и активация виртуального окружения

**Windows (PowerShell):**

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Windows (CMD):**

```cmd
python -m venv venv
venv\Scripts\activate.bat
```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
streamlit run main.py
```

После запуска приложение откроется в браузере по адресу `http://localhost:8501`.

> 📱 **Для открытия с телефона:** Подключите смартфон к той же сети Wi-Fi, что и компьютер, и откройте адрес из строки **Network URL**, которую выведет Streamlit в терминале.
