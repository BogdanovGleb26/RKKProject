# 📦 Где что лежит — Мобильная система учета и поиска по складу

Современное веб-приложение на Streamlit для оперативного поиска ТМЦ, основных средств, пластика для 3D-печати и расходных материалов на складе. Приложение автоматически подключается к Яндекс.Диску по REST API или читает локальный Excel-файл, считывает данные из многостраничного реестра и предоставляет адаптивный интерфейс, оптимизированный для работы как с компьютеров, так и с мобильных устройств.

---

## 🚀 Основной функционал

### 1. 🔍 Поиск по складу
- **Многостраничный поиск:** быстрое переключение между листами реестра
  (Закупки, ОС Главная, Пластик) через `segmented_control`.
- **Умный нерегистрозависимый поиск:** мгновенный фильтр по наименованию,
  артикулу/коду, куратору или месту хранения. Для коротких токенов (PLA, ASA,
  №4) — поиск по границам слова, для длинных — с учётом окончаний.
- **Информативные карточки (`st.expander`):** статус, количество/остаток, проект, ячейка хранения, стоимость, QR-код, куратор, отдел МТО.
- **Пагинация результатов:** не более 50 карточек на страницу — быстро даже при поиске по общим терминам («пластик»).
- **Быстрые фильтры:** кнопки-чипы для типовых запросов (PLA, Принтер, Смирнова, Цех №4 и т.д.).
- **Специальный запрос:** `без места` — показать позиции без указанной ячейки.
- **Сводка до поиска:** метрики «Всего позиций» и «Занято ячеек» на главном экране.
- **Кнопки «Сброс» и «Обновить»:** очистка поиска и принудительное перечитывание данных из источника.

### 2. 📊 Аналитика и Отчеты
3 KPI и 2 интерактивных графика (Plotly Express) — индивидуально для каждого
листа склада:

- **Закупки:** успешность поставок, загрузка ячеек, средняя нагрузка на
  кураторов МТО; stacked-bar «статусы × кураторы» и donut-чарт распределения
  статусов.
- **ОС Главная:** коэффициент ввода в эксплуатацию, объём готовых к выдаче ОС,
  доля неинвентаризированных позиций; размещение по проектам и топ-5 самых
  затратных отделов МТО.
- **Пластик:** суммарный вес филамента в кг, катушки с критическим остатком
  (< 200 г), запасы по типам пластика и раскладка по брендам.

Аналитика корректно обрабатывает «грязные» числа из Excel (пробелы, валюта,
разные десятичные разделители — `1,234.56` и `1.234,56`), а также показывает
предупреждение, если часть значений не удалось распарсить.

### 3. 📷 Сканер QR-кодов
- **Загрузка и камера:** файл с телефона/ПК (поддерживается multi-upload) или
  снимок напрямую с веб-камеры.
- **Многоэтапное распознавание (OpenCV):** предобработка кадра (grayscale,
  CLAHE, адаптивный порог, Otsu thresholding) для считывания повреждённых и
  тусклых QR-кодов.
- **Авто-ресайз:** большие фото автоматически уменьшаются для быстрого
  отображения и распознавания на мобильных устройствах.
- **Быстрый переход:** распознавание прямых веб-ссылок с кнопкой мгновенного
  перехода.

### 4. 📁 Выбор источника данных
- Динамический селект в сайдбаре: **Яндекс.Диск** или **Локальный ПК**.
- Рядом с каждым источником — индикатор статуса (✅ доступен / ⚠️ недоступен),
  размер файла и дата последней модификации.
- Кнопка «🔄 Проверить источники» для ручной перепроверки статусов.
- При переключении источника кеш данных автоматически сбрасывается — данные
  перечитываются «с нуля».

## 🛠️ Стек технологий

- Python 3.10+
- [Streamlit](https://streamlit.io/) — реактивный веб-интерфейс
- [Pandas](https://pandas.pydata.org/) & [python-calamine](https://pypi.org/project/python-calamine/) — обработка данных и сверхбыстрое чтение Excel
- [OpenCV](https://opencv.org/) (`opencv-python-headless`) & [Pillow](https://python-pillow.org/) — компьютерное зрение и обработка изображений для QR-сканера
- [Plotly](https://plotly.com/python/) — интерактивная визуализация данных
- [yadisk](https://pypi.org/project/yadisk/) — интеграция с API Яндекс.Диска
- [qrcode](https://pypi.org/project/qrcode/) — генерация QR-кодов для мобильного входа
- [python-dotenv](https://pypi.org/project/python-dotenv/) — безопасность и управление конфигурацией

## 📂 Структура проекта

Модульная структура обеспечивает чистоту кода и простоту масштабирования:

```text
├── main.py # Точка входа приложения, настройка страниц и роутинг
├── config.py # Загрузка переменных окружения и глобальные настройки
├── data_loader.py # Кешируемая загрузка Excel с Яндекс.Диска / локально
├── utils.py # Хелперы UI: подсветка текста, бейджи (HTML-safe)
├── views/ # Представления (экраны приложения)
│ ├── search_view.py # Модуль «Поиск по базе»
│ ├── analytics_view.py # Модуль «Аналитика и Отчёты» (Plotly)
│ └── scanning_view.py # Модуль «Сканер QR-кодов» (OpenCV)
├── logs/ # Логи приложения (не в git)
│ └── app.log
├── requirements.txt # Зависимости проекта
├── .env # Переменные окружения (секреты, в .gitignore)
├── .env.example # Шаблон переменных окружения
├── .gitignore # Исключения для Git
└── README.md # Документация проекта
```

## 📋 Подготовка и переменные окружения

Перед запуском создайте файл `.env` в корневой папке проекта со следующими параметрами:

```env
# Источник данных по умолчанию: "yadisk" или "local"
DATA_SOURCE=yadisk

# --- Яндекс.Диск ---
YANDEX_TOKEN=ваш_oauth_токен
DISK_PATH=/путь/к/файлу_на_диске.xlsx

# --- Локальный ПК ---
LOCAL_FILE_PATH=C:\path\to\registry.xlsx
```

Пример корректного файла `.env.example`:

```env
DATA_SOURCE=yadisk
YANDEX_TOKEN=y0_AgAAAA...
DISK_PATH=/Склад/Реестр_МТО.xlsx
LOCAL_FILE_PATH=C:\path\to\registry.xlsx
```

## ⚡ Инструкция по запуску

### 1. Клонирование репозитория

```bash
git clone https://github.com/BogdanovGleb26/RKKProject.git
cd RKKProject
```

### 2. Создание и активация виртуального окружения

**Windows (PowerShell):**

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Windows (CMD):**

```cmd
python -m venv venv
venv\Scripts\activate.bat
```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
streamlit run main.py
```

После запуска приложение откроется в браузере по адресу `http://localhost:8501`.

> 📱 **Для открытия с телефона:** Подключите смартфон к той же сети Wi-Fi, что и компьютер, и откройте адрес из строки **Network URL**, которую выведет Streamlit в терминале.

## 📝 Логирование
Все события загрузки данных и ошибки источников пишутся в logs/app.log.
Формат — дата [уровень] модуль: сообщение. Папка logs/ создаётся
автоматически при первом запуске и не коммитится в git.

## 🔄 Обновление данных
- Данные кешируются на 5 минут (@st.cache_data(ttl=300)).
- Кнопка «🔄 Обновить» в разделах поиска и аналитики сбрасывает кеш и перечитывает данные из активного источника.
- При смене источника данных в сайдбаре кеш также сбрасывается автоматически.
