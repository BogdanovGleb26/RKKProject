# 📦 Где что лежит — Мобильный поиск по складу

Минивеб-приложение на **Streamlit** для оперативного поиска предметов, расходников и деталей на складе. Приложение подключается к Яндекс.Диску, считывает данные из Excel-файла реестра и предоставляет адаптивный интерфейс для быстрого поиска с мобильных устройств.

---

## 🚀 Функционал

- **Быстрый поиск** по номенклатуре и коду товара (не регистрозависимый).
- **Кеширование данных** (`st.cache_data`) для минимизации запросов к Яндекс.Диску и ускорения работы.
- **Оптимизированное чтение Excel** с использованием сверхбыстрого движка `calamine`.
- **Компактные карточки** (`st.expander`) с выводом локации, остатка, статуса, QR-кода и куратора.
- **Статистика склада** на главном экране до ввода поискового запроса.

---

## 🛠️ Стек технологий

- **Python 3.10+**
- **Streamlit** — интерфейс приложения
- **Pandas** & **python-calamine** — обработка и быстрая загрузка таблиц
- **yaDisk** — интеграция с Яндекс.Диском API
- **python-dotenv** — управление конфигурацией и секретами

---

## 📋 Требования и подготовка

Перед запуском убедитесь, что у вас создан файл `.env` в корневой папке проекта со следующими переменными:

```env
YANDEX_TOKEN=ваш_oauth_токен_яндекс_диска
DISK_PATH=/Путь/К/Файлу/Реестр.xlsx

```

Пример корректного файла `.env.example`:

```env
YANDEX_TOKEN=y0_AgAAAA...
DISK_PATH=/Склад/Реестр_МТО.xlsx

```

## ⚡ Инструкция по запуску

### 1. Клонирование репозитория

```bash
git clone [https://github.com/ваш-username/название-репозитория.git](https://github.com/ваш-username/название-репозитория.git)
cd название-репозитория

```

### 2. Создание и активация виртуального окружения

**Windows (PowerShell):**

```powershell
# Если запуск скриптов заблокирован, разрешите его для текущей сессии:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

# Создание и активация venv
python -m venv venv
.\venv\Scripts\Activate.ps1

```

**Windows (CMD):**

```cmd
python -m venv venv
venv\Scripts\activate.bat

```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate

```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt

```

### 4. Запуск Streamlit

```bash
streamlit run app.py

```

*(Или через модуль Python: `python -m streamlit run app.py`)*

После запуска приложение откроется в браузере по адресу `http://localhost:8501`.

> 📱 **Для открытия с телефона:** Подключите смартфон к той же сети Wi-Fi, что и компьютер, и откройте адрес из строки **Network URL**, которую выведет Streamlit в терминале.
